# TBC 注入信息扩展候选（草稿，2026-09-17）

来源：作者本机的 WHOOP 能力调研（whoopdesk，未公开）（NOOP / OpenStrap / geniemax-core 文档与代码、WHOOP 官方 OpenAPI、本机 whoop-mcp 实测）。设备以 WHOOP 5.0 为主，写法尽量设备无关。

证据等级：**实测** = 本机真机拿到过；**文档** = 开源实现或官方文档写明、本机还没实测；**推测** = 只有间接依据。

TBC 标记：✅ 已在 v0.2 规范里 · ➕ 写进 v0.3 草案 · ❔ 格式已定、数据来源待实测 · 🔒 L2 敏感（格式已定，默认不注入）· 🚌 只在总线上流转、不进文本块 · 🔁 输出接口

**原则（用户 2026-09-17 定）**：TBC 是底层，能提供的都给规范格式，用不用由上层决定。按这个原则重排后的格式见 [spec-v0.3-draft-zh.md](spec-v0.3-draft-zh.md)。

## 1. 实时（秒级，读者此刻的身体）

| 数据 | 通道 | 粒度 / 延迟 | 证据 | TBC | 建议写法 / 原因 |
|---|---|---|---|---|---|
| 心率 | 标准心率服务 `2A37` | 1 秒 | 实测 | ✅ | 各相位 `hr` 统计、`series` |
| 心跳间隔 RR → HRV (RMSSD) | `2A37` | 每拍 | 实测 | ✅ | 相位 `hrv`、`rr-loss` |
| 戴上 / 摘下 | 私有通道事件 9 / 10 | 事件 | 文档 | ➕ | 进相位行：`read: … \| off-wrist 0:12`；摘下期间的心率不参与统计。比"页面切走"更直接地说明"人不在" |
| 手环双击 | 私有通道事件 14 | 事件 | 文档 | ➕ | 用保留 kind `button`：`button(whoop, event): read @41s ×1`。这是**读者主动**打的标记（"这一段有感觉"），唯一一个不靠推断的主观信号 |
| 身体动作（加速度 + 陀螺仪） | 私有通道原始流（约 100 Hz，每秒约 2 帧） | 秒级 | 文档 | ➕（有代价） | 新 kind `motion`，按相位只给摘要：`motion(whoop, 1s): read still 92% peak 0.4 g \| write …`。代替现在用 `rr-loss` 间接猜"手腕在动"。代价：费手环电、占蓝牙带宽，开源实现称会挤占手环存储，只能短时开（例如只在读回复时） |
| 光学原始波形 PPG | 私有通道原始流 | 25 Hz | 文档 | 🚌 | kind `ppg`，给想自己算指标的扩展；原始波形不进文本块 |
| 传感器贴合 / 信号质量 | 私有通道 + RR 缺失率 | 秒级 | 部分实测 | ✅ | 已有 `cov`、`rr-loss`；有了动作数据后可补充 |
| 电量 / 充电 | `2A19`、私有事件 3 / 7 / 8 | 分钟级 | 实测（电量） | ➕ | `sensor(whoop-5.0): battery 78% \| charging no \| worn yes`（L0） |
| 温度档事件 | 私有事件 17 | 事件 | 推测 | ❔ | 含义未核实 |
| 手环振动（输出） | 私有命令 | — | 文档 | 🔁 | v0.3 §5 输出接口：`tbc.registerActuator` / `tbc.actuate` / `<bio_act …/>`，默认关、限频 |

## 2. 准实时（分钟级，要从手环存储里读）

这些量在手环的历史记录里（约每秒一条），开源实现每 15 分钟拉一次。拉取会触发"确认后删除"。2026-09-17 初步实测（whoopdesk W2）：不发确认时手环只给第一段，之后的请求 60 秒无响应——"只读不删"拿不到最近数据；是否改为允许删除由用户决定。

| 数据 | 粒度 / 延迟 | 证据 | TBC | 建议写法 / 原因 |
|---|---|---|---|---|
| 皮肤温度 | 1 秒记录，延迟约 15 分钟 | 文档 | ❔ | `trend(…, lag 15m): skin …`（kind `skin_temperature`） |
| 呼吸频率 | 同上 | 文档 | ❔ | `trend` 行（kind `resp_rate`） |
| 血氧（红光 / 红外原始值） | 同上 | 文档 | 🚌 | 原始值走总线；日级血氧百分比走 `prior` |
| 手环算过的心率 | 同上 | 文档 | ❔ | 实时通道已有；历史补数据时可用于 `series` 回填 |
| 重力方向（姿势） | 同上 | 文档 | ❔ | `trend` 行（kind `posture`） |
