# 设备实测报告（欢迎补充）

TBC v0.3 §5 的触觉输出目前只在模拟设备上验证过（参数取自 buttplug 官方设备配置，8 款：谜姬 Mizz Zee、司沃康 Pulse Lite Neo / Mora Neo / Sam Neo、春风 Surge Pro / 黑洞 Plus / 元宇宙 2、The Handy）。**真实设备的结果需要大家补充。**

## 怎么测

1. 克隆本仓库，在仓库根目录起一个本地服务（任选其一）：`python3 -m http.server 8770` 或 `npx serve`。
2. 用桌面 Chrome / Edge 打开 `http://127.0.0.1:8770/tools/device-test.html`。
3. 选一条路线连接：
   - **浏览器直连**（buttplug-wasm，不用装软件；浏览器会弹窗选设备）；
   - **Intiface Central**（先在 Intiface 里点 Start Server 并连上设备）。
4. 依次点“轻点 / 两下 / 三下 / 心跳 / 波浪 / 持续”，再点“停止”；勾选四项检查；点“生成报告”。
5. 只测你自己拥有的设备。任何时候感觉不对，先点“停止”或关掉设备。

## 怎么提交

提一个 PR：在下表加一行，并把“生成报告”得到的 JSON 放进 `reports/` 目录（文件名 `日期-型号.json`，不要包含个人信息）。

| 日期 | 设备 | 路线 | 客户端 | 全部模式动了 | 停止立即生效 | 播完归零 | 强度有差别 | 报告 | 提交人 |
|---|---|---|---|---|---|---|---|---|---|
| 2026-09-17 | 8 款模拟设备（buttplug 配置 5.30） | Intiface（模拟器） | 5.x | 是 | 是 | 是 | 是（两档的收缩除外） | — | 维护者 |

## 已知情况

- 客户端版本要和服务端配套：Intiface Central（buttplug 服务端）的 `OutputCmd` 值是单个整数，用 JS 客户端 5.x；`buttplug-wasm` 3.0.0 依赖 JS 客户端 4.x（4.x 发数组格式）。测试页已按路线自动选择。
- 只有两档的输出（如收缩 `[0, 1]`）：强度低于 100% 时，按“向下取整”的实现不会动。
- 页面必须通过 http(s) 打开；直接双击本地文件时模块加载会失败。
