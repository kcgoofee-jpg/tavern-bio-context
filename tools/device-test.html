TBC 设备实测

用你自己的设备测一遍 Tavern Bio-Context 的触觉输出（v0.3 §5）：连接 → 逐个播放抽象模式 → 确认“停止”有效 → 生成报告，把报告以 PR 的形式补进 docs/device-test-reports-zh.md。只测你自己拥有的设备。页面需要桌面 Chrome / Edge，通过 http(s) 打开（不能直接双击本地文件）。
